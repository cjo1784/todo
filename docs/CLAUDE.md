# todo 프로젝트

할 일 → 주간 계획 → 1년 목표를 연결하는 할 일 관리 앱.

## 문서
- 요구 사항: `docs/PRD.md`
- 진행 계획: `docs/PLAN.md`

## 규칙
- 구현 범위는 PRD 기준. PRD에 없는 기능 추가 금지
- P0 완료 전 P1 착수 금지
- 작업 완료 시 `docs/PLAN.md` 체크박스 갱신
- 요구 사항 변경 시 `docs/PRD.md` 먼저 수정 후 구현
- 기술 스택 결정 시 `docs/PLAN.md`의 기술 스택 섹션 갱신

## 진행 방식
- 팀 진행: `dev-team-orchestrator` (PM → 백엔드 → 프론트엔드 → QA)
- 중간 산출물: `artifacts/`
