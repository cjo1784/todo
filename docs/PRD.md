# 할 일 관리 앱 PRD

## 1. Why. - 목적
- 흩어진 할 일, 주간 계획, 1년 목표를 한곳에서 관리
- 할 일 → 주간 계획 → 1년 목표 연결로 매일 하는 일이 어떤 목표에 쓰이는지 확인
- 상태를 드래그 앤 드롭으로 바꿔 관리 부담 줄이기
- 주간 진행률 자동 계산으로 수동 집계 없애기

## 2. Who. - 타깃 사용자
- 일일 할 일과 장기 목표를 함께 관리하려는 개인 사용자
- 주 단위로 계획하고 돌아보는 사용자
- 칸반(todo/doing/done) 방식에 익숙한 사용자

## 3. User Flow
0. GitHub 계정으로 로그인 (로그인 전에는 로그인 화면만 접근 가능)
1. 1년 목표 생성
2. 주간 계획 생성 → 1년 목표 연결
3. 일일 할 일 생성 → 주간 계획 연결
4. 칸반 보드에서 할 일 확인 (todo / doing / done)
5. 드래그 앤 드롭으로 상태 변경
6. 주간 진행률 자동 반영 확인
7. 할 일, 계획, 목표 수정·삭제

## 4. 기능 요구 사항

### P0 - 핵심 기능
- **할 일 CRUD**
  - 생성: 제목(필수), 날짜, 연결할 주간 계획
  - 조회: 일일 목록 / 칸반 보드
  - 수정: 제목, 날짜, 상태, 연결된 주간 계획
  - 삭제
- **상태 관리**
  - 상태 값: `todo` / `doing` / `done`
  - 생성 시 기본값: `todo`
- **드래그 앤 드롭 상태 변경**
  - 칸반 컬럼 간 카드 이동 시 상태 변경
  - 이동 즉시 저장
- **기간 구조**
  - 일일: 할 일
  - 주간: 주간 계획 (기간: 해당 주)
  - 1년: 1년 목표 (기간: 해당 연도)
  - 주간 계획, 1년 목표 CRUD
- **구조 연결**
  - 할 일 → 주간 계획 (N:1)
  - 주간 계획 → 1년 목표 (N:1)
  - 연결 해제 가능
- **주간 진행률 자동 반영**
  - 계산식: 연결된 할 일 중 `done` 개수 ÷ 전체 할 일 개수
  - 상태 변경, 생성, 삭제 시 즉시 다시 계산
  - 연결된 할 일 0개: 0% 표시
- **GitHub OAuth 로그인** (추가 2026-09-15)
  - 라우트: `/auth/github` (GitHub 인증 시작), `/auth/github/callback` (콜백)
  - 로그인 시 GitHub `username`, `avatar_url` DB 저장
  - 미로그인: 화면 → 로그인 페이지로 리다이렉트, API → `401`
  - 데이터 격리: 할 일·주간 계획·1년 목표 모두 본인 것만 조회/수정/삭제/연결
  - 로그아웃: 서버 세션 삭제 + 쿠키 삭제
  - 기존 데이터: `user_id` 필드 추가 마이그레이션
  - 설정 가이드 + `.env.example` 제공, `CLIENT_SECRET` 하드코딩 금지
  - 기존 CRUD 동작(검증·상태 코드·응답 형태·진행률·연결 해제) 변경 금지

### P1 - 추가 기능
- 1년 목표 진행률: 연결된 주간 계획 진행률 집계
- 기간별 필터 (일/주/연도)
- 목표 → 주간 계획 → 할 일 계층 뷰
- 상위 항목 삭제 시 하위 연결 처리 방식 선택 (연결 해제 / 함께 삭제)
